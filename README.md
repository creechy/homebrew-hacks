# Creechy Hacks

## How do I install these formulae?

`brew install creechy/hacks/<formula>`

Or `brew tap creechy/hacks` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "creechy/hacks"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
